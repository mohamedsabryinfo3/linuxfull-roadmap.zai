# مسار L→S — من Linux إلى محلل SOC 🗺️

موقع تعليمي تفاعلي لعرض مسار دراسي شخصي منظم: **Linux Administration** (16 مرحلة · 93 وحدة دراسية بدون تكرار) ثم خطة مرجعية **SOC Analyst L1→L2** (10 مراحل · 51 عنصرًا) بعد إتمام Security+ — مع سجل مصادر موثّق يوضح ما دُمج وما استُبعد ولماذا.

## ✨ المميزات

- **خريطة خط المسار (Transit Map)** تفاعلية في الواجهة: 16 محطة Linux → محطة تحويل Security+ → 10 محطات SOC، وتُضاء المحطات مع تقدمك الفعلي.
- **متابعة تقدم كاملة** محفوظة محليًا في المتصفح (localStorage): تعليم الدروس، ملاحظات شخصية لكل درس، حلقات تقدم لكل مرحلة، وبوابة انتقال SOC بحالة «جاهز للبدء».
- **تصدير / استيراد** التقدم والملاحظات كملف JSON (متوافق مع صيغة النسخة السابقة — تقدمك القديم ينتقل تلقائيًا).
- **بحث وفلاتر**: بحث نصي، تصفية (أساسي / إضافة مكملة / تطبيق عملي)، إخفاء المنتهي، بطاقة «الخطوة التالية» ذكية.
- **سجل المصادر الكامل**: 10 مصادر بقرارات الدمج والاستبعاد + 9 فهارس مفحوصة (112 عنصرًا).
- **متجاوب بالكامل**: يعمل على الجوال والتابلت والديسكتوب بدون أي تمرير أفقي.
- **ملف واحد ثابت** — لا يحتاج backend ولا build step.

## 🚀 الرفع على GitHub و Vercel

### GitHub
1. أنشئ مستودعًا جديدًا (Public أو Private).
2. ارفع محتويات هذا المجلد (الأهم `index.html` و`README.md`) إلى المستودع.

```bash
git init
git add .
git commit -m "Linux to SOC Learning Track"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

### Vercel
1. من لوحة Vercel اضغط **Add New → Project** واختر المستودع.
2. الإعدادات تُكتشف تلقائيًا (Framework Preset: **Other** / Static).
3. اضغط **Deploy** — الموقع سيكون متاحًا على رابط `*.vercel.app` مباشرة.

أو من الطرفية:

```bash
npm i -g vercel
vercel --prod
```
