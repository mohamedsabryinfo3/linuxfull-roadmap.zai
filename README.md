# Linux → SOC | Learning Roadmap — بنفس تصميم مرجع CCNA-to-SOC

موقع ثابت (Static Site) يعرض خطة **من Linux إلى SOC Analyst L1 → L2** (96 درسًا في 16 مرحلة + تبويب SOC مرجعي كامل + تدقيق 10 مصادر) **بنفس تصميم موقع المرجع** حرفيًا:

- نفس ملف CSS (خط IBM Plex Sans Arabic، خلفية `#eef1f6`، أكسنت برتقالي `#e8590c`، دعم Dark Mode التلقائي عبر `prefers-color-scheme`، `:focus-visible`، `prefers-reduced-motion`)، مع أنماط إضافية فقط للعناصر الجديدة (هدف المرحلة، تفاصيل الدرس، الملاحظات، تبويب SOC، تدقيق المصادر).
- نفس البنية والتفاعلات: هيرو + حلقة تقدم conic + زر «اذهب للدرس التالي»، تبويبات لاصقة، شيبس فلاتر (تصنيف/مرحلة)، بحث، إخفاء المنتهي، تصفير، خط زمني رأسي لكل مرحلة بلون خاص مع نقاط دائرية وشريط تقدم أخضر.

## المحتوى (كامل بدون أي نقص — منقول بالكامل من linuxfull-roadmapgpt.vercel.app)

- **96 درسًا** × كل الحقول: العنوان (رابط المصدر)، المصدر، المحاضر، الكورس، رقم الفصل، المدة، رقم التسلسل، التصنيف (75 أساسي / 20 استكمال مطلوب / 1 تطبيق عملي)، سبب الموضع، التطبيق المطلوب، نبذة عن المحاضر.
- **16 مرحلة** لكل منها: العنوان، الوصف، هدف المرحلة، المخرج المطلوب، الوقت التقديري.
- **تبويب SOC L1 → L2**: بوابة انتقال (Linux + Security+)، المحاور الأربعة (Log Analysis / MITRE ATT&CK / EDR / Hands-On SOC)، و10 مراحل مرجعية (s00–s09) بها 51 مهمة مع مصادرها وروابطها.
- **تدقيق المصادر**: 10 مصادر (المستخدم / غير المستخدم / سبب القرار) + الفهارس الكاملة (فصول أحمد عيد 12، مصطفى عبدالسلام 9، عبدالله النعيمي 28، فصول Security Jordan Part 1 ‏27 وPart 2 ‏11، عنصر Bash المؤكد، فيديوهات SOC الثلاثة).
- إجمالي وقت الفيديوهات المتاح: **36 ساعة و15 دقيقة** (5 دروس بمدة غير محددة في الفهرس).
- التقدم والملاحظات وبوابة SOC تُحفظ في `localStorage` (مفاتيح `linux-track-ccna` / `linux-track-notes` / `linux-track-soc` / `linux-track-gate`).

## التشغيل
