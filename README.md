# مسار LPIC-1 — تتبع الدروس

صفحة تتبع دروس كورس LPIC-1 (محاضر: محمد الطناني) — قايمة Timeline بـ 20 درسًا، وضع ليلي/نهاري، شريط تقدم، وتفاصيل قابلة للفتح لكل درس.

## هيكل المشروع

```
lpic-course-project/
├── index.html        ← هيكل الصفحة (Header + شريط التقدم + حاوية الـ Timeline)
├── css/
│   └── style.css     ← كل التنسيقات (متغيرات الثيم الليلي والنهاري + التجاوب للموبايل)
└── js/
    ├── data.js       ← بيانات الدروس العشرين (العنوان، المدة، التاريخ، الوصف، النقاط، المطلوب)
    └── app.js        ← المنطق: بناء الكروت، الأكورديون، الدوائر وشريط التقدم، التبديل بين الوضعين، الحفظ
```

## التشغيل

افتح `index.html` مباشرة بأي متصفح — لا يحتاج سيرفر ولا إنترنت (خط Cairo يُحمَّل من Google Fonts إن توفر الإنترنت فقط).

## التعديل الشائع

- **إضافة أو تعديل درس:** افتح `js/data.js` وأضف عنصرًا جديدًا في مصفوفة `LESSONS` بنفس الحقول (`n`, `title`, `dur`, `date`, `desc`, `points[]`, `tasks[]`) — الصفحة والترقيم وشريط التقدم يتحدثون تلقائيًا.
- **تغيير الألوان:** كل الألوان متغيرات CSS في أول `css/style.css` تحت `[data-theme="dark"]` و`[data-theme="light"]`.
- **تغيير اسم المحاضر أو عدد الدروس المعروض في الهيدر:** داخل `index.html` في العنصر `<p class="sub">`.

## ملاحظة على الحفظ

حالة المستخدم (الدروس المكتملة، المهام المنجزة، الوضع المختار) تُخزَّن في `localStorage` للمتصفح، بمفاتيح: `lpic1_done` و`lpic1_tasks` و`lpic1_theme`.

> يوجد أيضًا نسخة ملف واحد (`lpic-course-tracker.html`) بنفس الوظائف بالكامل، مناسبة للنقل السريع أو الفتح المباشر دون مجلد مشروع.
