# مسار L→S — من Linux إلى محلل SOC 🗺️

موقع تعليمي تفاعلي لعرض مسار دراسي شخصي منظم: **Linux Administration** (16 مرحلة · 99 وحدة دراسية بدون تكرار) ثم خطة مرجعية **SOC Analyst L1→L2** (10 مراحل · 51 عنصرًا) بعد إتمام Security+ — مع سجل مصادر موثّق يوضح ما دُمج وما استُبعد ولماذا.

## ✨ المميزات

- **خريطة خط المسار (Transit Map)** تفاعلية في الواجهة: 16 محطة Linux → محطة تحويل Security+ → 10 محطات SOC، وتُضاء المحطات مع تقدمك الفعلي.
- **اسم المحاضر ورقم الدرس ظاهران في القائمة**: كل درس يعرض في سطره المختصر اسم المحاضر ورقم الفيديو/الفصل داخل كورسه — للوصول السريع والبحث.
- **أكورديون «تفاصيل الدرس والمطلوب متي»** مطوي افتراضيًا (لا يفتح إلا بالضغط عليه حتى لا تُطال الصفحة): وصف الدرس + أهم النقاط المستفادة + قائمة «المطلوب متي» بصناديق دائرية تعلّم عليها عند إتمام فهم أو تطبيق كل نقطة.
- **متابعة تقدم كاملة** محفوظة محليًا في المتصفح (localStorage): تعليم الدروس، تعليم نقاط الفهم لكل درس، ملاحظات شخصية لكل درس، حلقات تقدم لكل مرحلة، وبوابة انتقال SOC بحالة «جاهز للبدء».
- **تصدير / استيراد** التقدم والملاحظات ونقاط الفهم كملف JSON (متوافق مع صيغة النسخ السابقة — تقدمك القديم ينتقل تلقائيًا).
- **بحث وفلاتر**: بحث نصي (يشمل النقاط وأسئلة الفهم وأسماء المحاضرين وأرقام الدروس)، تصفية (أساسي / إضافة مكملة / تطبيق عملي)، إخفاء المنتهي، بطاقة «الخطوة التالية» ذكية.
- **سجل المصادر الكامل**: 10 مصادر بقرارات الدمج والاستبعاد + 8 فهارس مفحوصة (100 عنصرًا).
- **متجاوب بالكامل**: يعمل على الجوال والتابلت والديسكتوب بدون أي تمرير أفقي.
- **موقع ثابت (Static)** — لا يحتاج backend ولا build step ولا أي تثبيت حزم.

## 📁 هيكل المشروع

```

├── index.html              ← هيكل الصفحة (HTML فقط — التخطيط والأقسام)
```

> 🔎 **لتعديل المحتوى** (دروس، مراحل، مصادر، أهم النقاط وأسئلة الفهم لكل درس): كل شيء في `assets/js/data.js` — كائن واحد `ROADMAP_DATA` بنفس بنية الموقع الأصلي.
> **لتعديل التصميم**: `assets/css/style.css`. **المنطق**: `assets/js/app.js`.

## 🚀 الرفع على GitHub و Vercel

### GitHub
1. أنشئ مستودعًا جديدًا (Public أو Private).
2. ارفع كل محتويات هذا المجلد (index.html + مجلد assets + vercel.json + README).

```bash
git init
git add .
git commit -m "Linux to SOC Learning Track"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

### Vercel
1. من لوحة Vercel اضغط **Add New → Project** واختر المستودع.
2. الإعدادات تُكتشف تلقائيًا (Framework Preset: **Other** / Static — لا Build Command ولا Output Directory).
3. اضغط **Deploy** — الموقع سيكون متاحًا على رابط `*.vercel.app` مباشرة.

أو من الطرفية:

```bash
npm i -g vercel
vercel --prod
```

## 🗄️ البيانات والتقدم

- المحتوى كامل داخل `assets/js/data.js` — لا يحتاج قاعدة بيانات ولا سيرفر.
- تقدم الدراسة والملاحظات ونقاط الفهم المعلّمة تُحفظ على جهاز المستخدم فقط (localStorage)؛ استخدم أزرار التصدير/الاستيراد من قائمة ⋯ العلوية لنقلها بين الأجهزة.
